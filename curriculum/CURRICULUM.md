# Curriculum — the team's school

Goal: distill publicly available top-tier knowledge about sales websites into **operational rules with numbers**, not essays. Every rule must be applicable and checkable.

## Sources by domain

### 1. Awards — the visual language of the top (2024–2026)
- Awwwards (Site of the Year / Site of the Month, e-commerce category)
- FWA (Favourite Website Awards)
- CSS Design Awards (WOTY)
- Webby Awards (Best Shopping / E-commerce)
- D&AD (Digital Design)
- **Caution**: awards teach the aesthetic language, NOT conversion. Never copy experimental patterns into a checkout.

### 2. E-commerce CRO — what actually sells
- Baymard Institute (product page, checkout, mobile — publicly available findings)
- Nielsen Norman Group (e-commerce UX)
- CXL (conversion studies)
- GoodUI (A/B test patterns)

### 3. Typography
- Butterick's Practical Typography
- Typewolf, Fonts In Use (pairing in practice)
- Refactoring UI (scale, hierarchy)

### 4. Color and color systems
- Radix Colors / Tailwind color science (scales, accessibility)
- WCAG 2.2 contrast
- Color-psychology research by product category (Labrecque & Milne and newer)

### 5. Layout and spacing
- 8pt grid literature, Refactoring UI
- Material Design 3 / Apple HIG (spacing, touch targets)
- Above-the-fold anatomy analysis of top shops

### 6. Motion and performance
- Emil Kowalski (Animations on the Web), Material motion specs
- web.dev Core Web Vitals (budgets: LCP, CLS, INP)
- Image strategy (formats, lazy loading)

### 7. Copy and strategy
- Harry Dry — Marketing Examples (copywriting formulas)
- Julian Shapiro — Handbook (landing pages)
- April Dunford — positioning
- VWO / Unbounce CTA and headline studies

## Distillation rules

1. Every finding → a rule with a number wherever possible ("line length 45–75ch", not "comfortable line length").
2. Every rule carries its source.
3. Anti-patterns are recorded explicitly (what NOT to do and why).
4. Trends are separated from laws: a trend has a date and a shelf life; a law (contrast, hierarchy) does not.
5. Every skill ships a checklist QA can verify.
6. Distillation-completeness check: after any research → skill wave, diff the research
   files' topic headings against the shipped skills' rule groups — content that was
   researched but never distilled is a pipeline defect, not a judgment call (this
   pipeline once lost pricing-page and SEO-metadata research for a full wave before an
   audit caught it).
